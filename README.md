# SlideUP - منصة العروض التقديمية الاحترافية

منصة متكاملة لإنشاء وتحرير العروض التقديمية بشكل احترافي مع دعم كامل للغة العربية.

## 🚀 المميزات

- ✨ محرر عروض تقديمية متقدم
- 🎨 مكتبة ضخمة من القوالب والأيقونات
- 🤖 مساعد ذكاء اصطناعي
- 📊 رسوم بيانية تفاعلية
- 🎬 أنيميشن وانتقالات سلسة
- 💾 حفظ تلقائي وسجل إصدارات
- 🌙 وضع داكن/فاتح
- 🌐 دعم كامل للغة العربية
- 📱 تصميم متجاوب

## 📋 المتطلبات

- Node.js 18+
- npm أو yarn

## 🛠️ التثبيت

```bash
npm install
```

## 🚀 التشغيل

### Development Mode
```bash
npm run dev
```

### Production Mode
```bash
npm run build
npm run preview
```

## 📦 البناء للإنتاج

```bash
npm run build
```

سيتم إنشاء ملفات الإنتاج في مجلد `dist/` (موقع ثابت 100% بدون باك اند).

## 🗄️ تخزين البيانات

المشروع يعمل بالكامل في المتصفح (Frontend Only):
- جميع البيانات تُحفظ محلياً في `localStorage` عبر `src/lib/storage.ts`
- لا يوجد سيرفر ولا قاعدة بيانات
- يمكن رفع مجلد `dist/` على أي استضافة ثابتة (Netlify, Vercel, GitHub Pages, ...)

## 📁 هيكل المشروع

```
slideup/
├── src/                    # كود الواجهة (React)
│   ├── components/        # المكونات
│   ├── pages/            # الصفحات
│   ├── contexts/         # Context API
│   ├── hooks/            # Custom Hooks
│   ├── data/             # البيانات الثابتة
│   └── lib/              # المكتبات المساعدة
├── public/               # الملفات الثابتة
└── dist/                 # ملفات الإنتاج (بعد البناء)
```

## 🌐 الرفع على الإنتاج

المشروع موقع ثابت (Static Site):
1. شغّل `npm run build`
2. ارفع محتويات مجلد `dist/` على أي استضافة ثابتة
3. ملف `netlify.toml` جاهز للنشر على Netlify مع دعم React Router
